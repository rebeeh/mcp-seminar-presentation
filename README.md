# Model Context Protocol (MCP) - Interactive Seminar Presentation

An interactive, 21-slide presentation deck designed for technical seminars and deep-dive architectural discussions on the **Model Context Protocol (MCP)**. Built with responsive HTML, modern CSS glassmorphism, and lightweight vanilla JavaScript.

---

## 🌟 Key Features

* **Apple-Inspired Design System:** Spatial whitespace, glassmorphism UI, gradient typography, and animated micro-interactions.
* **Zero Build Overhead:** Standalone single-file HTML execution that runs natively in any browser.
* **Multi-Input Navigation:**
  * ⌨️ **Keyboard Shortcuts:** Navigate using Arrow Keys, Spacebar, Page Up, and Page Down[cite: 1].
  * 🖱️ **Edge Clicking:** Click on the left 20% of the screen to go back, or the remaining 80% to advance[cite: 1].
  * 📱 **Touch Support:** Native swipe gestures on mobile and tablet devices[cite: 1].
* **Dynamic Progress Indicator:** Real-time top progress line tracking slide completion[cite: 1].
* **GitHub Pages Ready:** Instant web deployment with zero configuration required[cite: 1].
